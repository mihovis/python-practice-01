# Калькулятор стоимости покупки

Консольное приложение на Python для расчёта стоимости покупки с учётом скидок, способов доставки и промокодов.

## Описание

Программа решает задачу автоматизации расчёта чека для одной товарной позиции. Пользователь вводит параметры товара, после чего программа рассчитывает скидку и выводит чек.

## Функционал

### Основные возможности
- Консольный ввод наименования товара, цены и количества.
- Проверка входных данных.
- Система скидок:
  - 5% при сумме от 5 000 до 9 999 руб.
  - 10% при сумме от 10 000 до 14 999 руб.
  - 15% при сумме от 15 000 руб.

### Дополнительный функционал
- Выбор способа доставки (самовывоз или курьер с бесплатной доставкой от 10 000 руб.).
- Промокод `BONUS5` (даёт +5% к скидке).
- Начисление бонусных баллов (3% кешбэк).

## Инструкция по запуску

1. Python 3.8+.
2. Запустите скрипт через терминал:
   ```bash
   python main.py
   ```
